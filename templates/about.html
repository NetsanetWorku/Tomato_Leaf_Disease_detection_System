About This Project

AI-Based Tomato Leaf Disease Detection System Using CNN

🎯 Project Overview

This system uses a Convolutional Neural Network (CNN) trained on the PlantVillage dataset to automatically detect and classify tomato leaf diseases from digital images. It was developed as an AI project at Madda Walabu University, College of Computing.

The goal is to provide farmers and agricultural workers with an accessible, fast, and accurate tool for early disease detection — without requiring expert agricultural knowledge.

🧠 Model Architecture

  • Type: Custom CNN + MobileNetV2 Transfer Learning
  • Input: 128 × 128 × 3 RGB images
  • Output: 10-class Softmax classification
  • Layers: Conv2D, BatchNorm, MaxPool, Dropout, Dense
  • Optimizer: Adam (lr = 0.001)
  • Loss: Categorical Cross-Entropy
  • Expected Accuracy: ~93%

📊 Dataset

  • Source: PlantVillage Dataset
  • Total Images: 8,496
  • Classes: 10 (1 healthy + 9 diseased)
  • Split: 70% Train / 15% Validation / 15% Test
  • Augmentation: Flip, Rotation, Zoom, Brightness

🛠️ Technologies Used

Python 3.x TensorFlow / Keras OpenCV NumPy Scikit-learn Flask Matplotlib Seaborn Google Colab PlantVillage
